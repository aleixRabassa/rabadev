RabaDev

RabaDev is a personal publishing tool. It lets its owner upload videos they created to their own YouTube channel and TikTok account, directly from their computer, using an AI assistant.

What it does

  • Uploads a video file the user selects, with the title, description and privacy setting the user chooses.
  • Shows the user basic statistics for their own videos, such as views and likes.

What it does not do

  • It does not post anything the user has not explicitly asked it to post.
  • It does not access other people's accounts, read private messages or collect data for advertising.
  • It does not run on a server: credentials stay on the user's own computer.

It uses the official YouTube Data API (YouTube API Services) and the TikTok Content Posting and Display APIs.
